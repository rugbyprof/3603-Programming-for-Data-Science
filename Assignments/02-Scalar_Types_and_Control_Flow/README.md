# 📂 Module 02: Scalar Types and Control Flow

This module combines a review of scalar data types (`int`, `float`, `str`, `bool`) and arithmetic with an introduction to Python control flow using `if`, `elif`, and `else`.

---

## 🔗 Assignments

| Notebook | Description |
|----------|-------------|
| [01-Scalar_Types.ipynb](01-Scalar_Types.ipynb) | Practice Python's basic scalar types, arithmetic operators, type casting, and comparison operators. |
| [02-Control_Flow.ipynb](02-Control_Flow.ipynb) | Learn how to use `if`, `elif`, `else`, and logical operators to control program logic. |

Each notebook ends with an optional **🔥 Challenge** section — a harder variant if you want to push past the core material. Skipping it won't hurt you later in the course.

---

## 🧠 Learning Goals

- Recognize and use Python scalar types (`int`, `float`, `str`, `bool`)
- Perform arithmetic operations and convert between types with casting
- Write conditional expressions using comparison and logical operators
- Use `if`/`elif`/`else` to create decision-making programs, including branches with multiple lines
- Recognize `match`/`case` when you see it

`02-Control_Flow.ipynb` also includes side-by-side comparisons to C++ (`&&`/`||`/`!`, chained comparisons, `switch` vs. `match`, and `?:`) for anyone coming from this program's early C++ coursework.

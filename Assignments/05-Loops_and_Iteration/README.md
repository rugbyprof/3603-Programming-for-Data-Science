# 📂 Module 05: Loops and Iteration

This module explores looping in Python using `for` and `while` loops, plus `enumerate()` and `zip()` for the situations a plain loop doesn't handle cleanly, and the `with` construct for safely reading files.

---

## 🔗 Assignments

| Notebook | Description |
|----------|-------------|
| [01-For_Loops.ipynb](01-For_Loops.ipynb) | `for` loops over lists, strings, and `range()`, plus `enumerate()`, `zip()`, and nested loops. |
| [02-While_Loops.ipynb](02-While_Loops.ipynb) | `while` loops, `break`/`continue`, infinite loops (and recovering from one), and sentinel-controlled loops. |
| [03-File_Loops_and_With.ipynb](03-File_Loops_and_With.ipynb) | Reading files safely with `with`, looping over lines, and handling a missing file with `try`/`except`. |

Each notebook ends with an optional **🔥 Challenge** section — a harder variant if you want to push past the core material. Skipping it won't hurt you later in the course.

---

## 🧠 Learning Goals

- Use `for` loops with `range()`, strings, and other iterables
- Use `enumerate()` and `zip()` to loop with index or in parallel
- Control loop repetition using `while` and boolean conditions
- Use `break` and `continue` to manage loop flow, and recover from an infinite loop
- Read files using `with open(...) as f:` and iterate over lines, handling a missing file gracefully

`02-While_Loops.ipynb` and `03-File_Loops_and_With.ipynb` both include short C++ comparisons (`do`/`while`, and RAII vs. `with`) for anyone coming from this program's earlier C++ coursework.

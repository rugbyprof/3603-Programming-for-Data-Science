# 📂 Module 01: Working with Data (Basic)

In this module, you'll learn how to manipulate and explore Python's built-in data containers: lists, tuples, and dictionaries. These are the essential building blocks used in real-world data science tasks.

---

## 🔗 Assignments

| Notebook | Description |
|----------|-------------|
| [01-Lists.ipynb](01-Lists.ipynb) | Create and manipulate lists using indexing, slicing, and built-in methods; combine lists with `+` / `append()` / `extend()`, build nested (2D) lists, delete items, and iterate by index with `range(len(...))` and `enumerate()`. |
| [02-Tuples.ipynb](02-Tuples.ipynb) | Understand tuples, their immutability, and when to use them. |
| [03-Dictionaries.ipynb](03-Dictionaries.ipynb) | Create and access key-value pairs; work with a list of dictionaries as table rows, look records up and update them by row number, and see how JSON and GeoJSON map directly onto Python lists and dictionaries. |

Each notebook ends with an optional **🔥 Challenge** section — a harder variant if you want to push past the core material. Skipping it won't hurt you later in the course.

---

## 🧠 Learning Goals

- Use Python lists for storing and processing sequential data.
- Distinguish `+`, `append()`, and `extend()`, and build and traverse nested (2D) lists.
- Remove list items with `remove()`, `pop()`, `del`, and `clear()`.
- Iterate by index using `range(len(...))` and `enumerate()`.
- Understand the use of tuples and their immutability.
- Manipulate and access data using dictionaries.
- Model tabular data as a list of dictionaries and update records by row number.
- Recognize how JSON and GeoJSON are just nested Python lists and dictionaries.

# 📊 Module 08: Describing and Visualizing Data

This module moves beyond raw numbers and starts making sense of data through **description** and **visualization**. You'll learn how to classify different types of data, compute meaningful summary statistics, and create visualizations using Matplotlib and Seaborn.

The module culminates in a mini-lab, where you'll explore trends and outliers in a real dataset. By the end, you should feel comfortable turning numbers into insights.

All notebooks use the local `penguins.csv` in this folder — no network download required.

---

## 🎯 Learning Goals

- Distinguish between different types of data (qualitative vs. quantitative, scales of measurement)
- Compute and interpret summary statistics (mean, median, variance, IQR, skewness, etc.)
- Build basic plots with Matplotlib (line, bar, scatter, histogram)
- Use Seaborn for more advanced, stylish visualizations
- Identify trends and outliers in data using visual tools

## 🛠️ Tools & Libraries

- **Pandas** → data handling and summary statistics
- **SciPy** (`scipy.stats`) → skewness, kurtosis, mode
- **Matplotlib** → foundational plotting library
- **Seaborn** → high-level visualization built on Matplotlib

If any of these aren't in your `.venv` yet, check `_StartHere` for how to install from `requirements.txt`.

# 📂 Module 04: Functions

Functions are how you package up logic to reuse it, instead of copying and pasting. This module covers defining and calling functions, flexible argument patterns (`*args`/`**kwargs`), and how Python — a dynamically typed language — handles the situations where other languages would use function overloading.

(This module does **not** cover classes/OOP — just functions.)

---

## 🧠 Learning Goals

- Define and call functions with parameters, `return` values, and default arguments
- Understand local vs. global scope
- Accept a flexible number of arguments with `*args` and `**kwargs`
- Branch a function's behavior based on the type of its input, and recognize this as Python's answer to overloading
- Recognize duck typing as an alternative to explicit type checks

If you've worked with C++, `03-Type_Based_Behavior.ipynb` speaks directly to you — it starts from "why can't I just overload this function?" and works forward from there.

# 🏗️ Module 06: Foundations

This module moves beyond core Python and into the Jupyter/IPython tooling you'll use for the rest of the course: magic commands, Markdown, file and data I/O, plotting basics, productivity shortcuts, getting help, and measuring performance.

Unlike the earlier language modules, this one is about *tools*, not new language concepts — so notebooks here lean on "Your Turn" prompts you work directly rather than heavy multi-tier practice sets.

---

## 📚 Notebooks

1. [01-magic_commands.ipynb](01-magic_commands.ipynb) — IPython magics like `%pwd`, `%whos`, `%%writefile`, `%debug`, and `%lsmagic`.
2. [02-markdown_and_formatting.ipynb](02-markdown_and_formatting.ipynb) — Markdown basics: headings, lists, links, images, and LaTeX math.
3. [03-working_with_files_and_paths.ipynb](03-working_with_files_and_paths.ipynb) — Navigating directories, and reading/writing text, JSON, and CSV files with `with`.
4. [04-data_input_output.ipynb](04-data_input_output.ipynb) — Reading/writing data with Pandas, and exploring a DataFrame with `.head()`/`.info()`/`.describe()`.
5. [05-plotting_basics.ipynb](05-plotting_basics.ipynb) — Simple line, scatter, and bar plots with Matplotlib.
6. [06-jupyter_shortcuts_and_productivity.ipynb](06-jupyter_shortcuts_and_productivity.ipynb) — Command vs. Edit mode, keyboard shortcuts, exporting notebooks, `%history`.
7. [07-using_help_and_docs.ipynb](07-using_help_and_docs.ipynb) — Using `?`, `??`, `help()`, tab completion, and external docs.
8. [08-timing_and_performance.ipynb](08-timing_and_performance.ipynb) — `%time`/`%timeit` in depth, and comparing loops vs. NumPy.

Each notebook ends with a **🏋️ Practice** section and an optional **🔥 Challenge**.
